# Contributing

- Preserve evidence-first claims and explicit unknown states. Never fabricate assessment scores, sources, citations, or learning history.
- No immutable learning-style taxonomy or pseudoscientific cognitive/neurological diagnosis.
- All new skill frontmatter must follow the open Agent Skills spec and remain under **8,000 characters** per SKILL.md; put details in bundled references.
- Scripts must remain stdlib-only or document optional dependencies clearly.
- Add regression tests for every schema/protocol change. Any capability claim requires a test or a clearly marked manual check.
- No personal assessment transcripts, private paths, secrets, or logs in PRs.
- Cross-platform adapter updates require official documentation verification and test notes.
